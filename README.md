# UMKM Jatisampurna

Aplikasi web UMKM Jatisampurna terdiri dari dua bagian: **UMKM-API** (backend Laravel) dan **UMKM-APP** (frontend React + Vite).

---

## Cara Menjalankan Project

### 1. Aktifkan Backend (UMKM-API)

Masuk ke folder `UMKM-API`, lalu jalankan server Laravel:

```bash
cd UMKM-API
php artisan serve
```

Backend akan berjalan di `http://localhost:8000`.

---

### 2. Jalankan Frontend (UMKM-APP)

Buka terminal baru, masuk ke folder `UMKM-APP`, lalu jalankan:

```bash
cd UMKM-APP
npm run dev
```

Frontend akan berjalan di `http://localhost:5173`.

Buka browser dan akses: **http://localhost:5173**
